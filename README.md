# Nexora — 3D Animated Landing Page

A professional landing page with a real-time 3D background, built with [Three.js](https://threejs.org/).

## Features
- WebGL scene: iridescent torus knot, wireframe shell, orbit rings, floating shapes and a 4,000-particle starfield
- Bloom post-processing
- Scroll-linked camera choreography and pointer-reactive lighting/parallax
- 3D tilt cards, scroll reveal animations and animated counters
- Responsive layout with mobile menu; respects `prefers-reduced-motion`

## Run locally
No build step needed:

```bash
python -m http.server 5173
# open http://localhost:5173
```

## Deploy
Static site, hosted on GitHub Pages.
